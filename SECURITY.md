# Security policy

Report a vulnerability privately, through GitHub's private vulnerability
reporting: [report a vulnerability](https://github.com/TimmyBurn2/HeXO-Arena/security/advisories/new),
also under the repository's Security tab.
Never report one in a public issue.

Say what the problem is, how to reproduce it, and what it lets someone do.

In scope: this repository's code, and a deployment run from it.

There is no bug bounty.
